# Prompt｜从需求到可验收交付

> 背景：【项目是什么】  
> 要做的改动：【一句话描述】  
> 输入：【文件、表或接口】  
> 必须满足：【列出 3 条】  
> 绝对不能做：【列出限制】  
> 验收方式：【测试命令、可见结果或人工检查方法】
>
> 请按四阶段执行：
> 1. Explore：只读扫描必要文件并描述已有逻辑，不修改。
> 2. Plan：列出预计修改文件、风险和最小方案。
> 3. Build：我确认方案后，完成最小改动，不拓展范围。
> 4. Verify：运行检查，记录真实命令和结果；审查 diff；汇报通过项、失败项、未验证项。
>
> 未获得明确许可前，不提交到远程仓库、不改线上配置、不触达客户、不执行付款。
