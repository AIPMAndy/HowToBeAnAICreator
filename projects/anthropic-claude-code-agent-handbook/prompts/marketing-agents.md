# Prompt｜双子 Agent 广告迭代（教学复刻）

来源灵感：Anthropic 增长营销团队公开报告 p15–16。**以下 Prompt 为本项目原创**，不代表其内部原始 Prompt。

## 开场任务

> 现在只处理我提供的虚构广告 CSV 和公开产品描述。先计算 CTR/CPC、找出候选低表现广告。不要连接投放账户，不要投放或调整预算。所有建议须标注“待测试”，不能声称提高转化率。

## 标题 Agent

> 你只负责标题。根据产品的**已证实**卖点，为每条待改进广告给出 5 个互不重复的标题。每个标题最多 30 个字符（教学约束；正式发布前根据目标平台最新规范重新检查）。不能编造价格、收益、身份或夸张保证。输出 CSV：ad_id,title,idea,hypothesis。

## 描述 Agent

> 你只负责描述。不复用标题 Agent 的整句。针对同一广告给出 5 条描述，每条最多 90 个字符（教学约束）。讲清受众、功能和真实行动，不捏造用户证言。输出 CSV：ad_id,description,idea,hypothesis。

## 审核者

> 检查全部候选文案：字符数、语义重复、事实依据、敏感词、是否与输入产品信息一致、是否暗示保证收益。把不合规候选剔除，原因写清楚。不能替代广告平台正式政策审核，也不能自动上线。

## 评估闭环

- 实验前记录唯一变量和对照组。
- 保留投放时段、受众、预算和归因口径。
- 不用单条广告表面涨跌直接断言因果关系。
- 上线前人工批准；真实数据按权限和隐私约束处理。
