# 业务流程转 AI 实战方案

当用户希望把某个业务工作交给 Claude Code 或 Agent 时：

1. 明确业务触发器、输入、输出、权限、失败代价及频次。
2. 优先画出现有人工步骤，删除不创造价值的动作。
3. 判断确定性规则是否足够。能用小脚本处理就不用复杂 Agent。
4. 写 3 条可检验的完成标准与 3 个典型失败场景。
5. 选择最简架构：普通脚本 / 单 Agent / Skill / Subagent / 编排者—工作者。
6. 拟定最小原型；优先使用虚构或脱敏数据。
7. 提供测试与回滚方案，明确必须人工审核的动作。
8. 输出五部分：流程图（文字即可）、方案、成本项、验收表、下一步。

不可宣称部署或商业转化已完成；没有实际测量数据就写“待验证”。如需部署、发信、投放、付款、修改生产数据，先取得授权。
