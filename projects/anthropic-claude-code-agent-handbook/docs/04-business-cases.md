# 04｜不写代码也能复刻：营销、管理、法务、数据、产品

> 本章所有实施步骤均为**我们设计的教学方案**，不是 Anthropic 私有系统的源码或复制版。真实业务数据必须先脱敏并确认访问授权。

## 案例 A｜AI 获客：广告表现 → 两个 Agent → 审核 → 人工上线

**灵感来源**：Anthropic 增长营销团队在公开 PDF 的 p15–16 描述了广告 CSV、标题/描述双子 Agent、Figma 批量变体与 Meta Ads MCP。

### 手把手实施

**第一步：确定性诊断**
- 准备广告 CSV：曝光、点击、花费、文案、活动名。
- 先用脚本计算 CTR = 点击 / 曝光；CPC = 花费 / 点击（0 点击要特殊处理）。
- 使用 [本项目可运行的 Python 演示](../examples/ads/README.md) 生成低表现清单。

**第二步：拆职责**
- 标题 Agent：只写标题，遵守平台字符数和真实卖点。
- 描述 Agent：只写描述，明确受众、产品、行动。
- 审核者：检查字符限制、事实、夸张承诺、敏感词和是否与原品牌一致。

**第三步：小规模实验**
- 保存每个变体、发布时间、版本、成本、假设。
- 严格区分自然波动与真实提升；不要把相关性说成因果。
- 不允许 Agent 自动执行付款、改预算或上线，必须人工审核。

[双子 Agent Prompt →](../prompts/marketing-agents.md)

**产出**：CSV 诊断表、候选文案、人工审核记录、下一次实验假设。

## 案例 B｜企业咨询团队：需求记录自动生成交付清单

**输入**：一份已脱敏的客户需求访谈纪要。
**操作**：
1. AI 整理为：目标、现状、约束、未知、责任人。
2. AI 生成里程碑和验收条件。
3. 专人检查：是否虚构了承诺、价格、交付期限。
4. 确认后再存入项目台账。

**产出**：可审查的行动清单。**不自动承诺服务效果**。

## 案例 C｜财务团队：自然语言说明 → 数据表

**灵感来源**：Anthropic 数据基础设施团队辅助财务同事描述查询与 Excel 输出。

**实施**：
1. 用虚构数据演练。
2. 写清楚统计口径（例如净收入和流水不同）。
3. 先生成字段映射与计算公式，财务负责人确认。
4. 再运行有权限、只读的查询或本地脚本。
5. 对总数做独立复核。

**产出**：报表、数据口径说明、复核表。

## 案例 D｜产品设计：截图 → 可点击原型

**实施**：
1. 给设计截图；声明只用于自有或已授权设计。
2. 描述交互状态：空、加载、成功、失败、无权限。
3. Claude Code 生成原型。
4. 手工检查各状态和移动端显示。
5. 展示给真实用户，再决定是否生产化。

**产出**：原型 URL/本地项目、测试清单。

## 案例 E｜企业知识：技术文档 → 员工入职助手

1. 选 5 份可共享制度文档。
2. 建立索引文件，注明最后更新日期。
3. 要求 AI **引用原文段落**回答，不知道就说未知。
4. 收集 20 个员工常见问题做测试。
5. 对错答逐项修正源文档、工具与规则。

**产出**：入职 FAQ、来源清单、20 题评估记录。

## 如何挑第一个 Agent 项目？

按 5 个问题评分（每项 0/1）：

| 判断标准 | 是则 1 分 |
| --- | --- |
| 每周重复两次以上 | 1 |
| 输入能拿到且合法 | 1 |
| 输出能客观检查 | 1 |
| 失败可回滚、影响有限 | 1 |
| 成本可测，能和人工基线比较 | 1 |

**建议**：优先练习 4–5 分的任务。0–2 分先做流程梳理，不急着 Agent 化。以上分数是本项目的建议筛选规则，**不是 Anthropic 官方量表**。

业务价值用实际时间、返工率、正确率和获取线索的质量来测，不承诺赚多少钱。
