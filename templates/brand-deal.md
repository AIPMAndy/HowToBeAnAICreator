# 品牌合作实操模板

## 1. 一页媒体资料

```text
账号名称：[ ]
内容定位：[ ]
服务受众：[ ]
平台与统计日期：[ ]
粉丝/近30天数据（真实且说明口径）：[ ]
代表作品1：[链接 + 实测内容]
代表作品2：[链接 + 实测内容]
代表作品3：[链接 + 实测内容]
可交付形式：[实测短视频 / 教程图文 / 公众号长文]
合作原则：基于真实测试；不虚构效果；依法进行AI内容和商业广告标识。
商务联系：[按平台规则提供]
```

## 2. 收到询价怎么回

> 感谢联系。为准确评估合作，请先确认：产品和落地页、目标受众、平台与交付数量、发布日期、是否需要品牌审核、修改轮数、是否涉及授权投流、预算范围和结算节点。我测试产品可用后，会按交付与授权范围提供书面报价。内容仅基于实际测试，不保证不可控的播放和成交数据。

## 3. 书面报价检查

- 产品是否可实测，限制在哪里？
- 内容拍摄制作与发布服务是否分别列明？
- 修改几轮、超范围怎样计费？
- 授权期限和范围：自然发布、品牌自用、广告投流、二次剪辑？
- 是否有同类产品排他？期限与费用？
- 合同主体、发票、税费、定金、尾款与逾期支付？
- 内容生成合成和商业推广标识是否按平台规则执行？

## 4. 商单台账口径

询盘 ≠ 报价 ≠ 签约 ≠ 完成发布 ≠ 实际回款。不同阶段分别统计。不要用尚未签约的询盘宣传实际收入。拒绝保证金骗局、账号密码索取和虚假数据要求。
