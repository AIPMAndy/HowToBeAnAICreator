# 可复制 Prompt · 先实测，再做内容

使用说明：把方括号里的内容替换为真实素材；不要上传客户、求职者或他人隐私；人工核实生成结果。Prompt 不是保证效果的魔法语句。

## 01 新闻核验

```text
请把以下 AI 新产品消息拆成：【官方已证实】【官方宣传但未验证】【我需要亲自实测】三栏。列出产品入口、支持地区、费用、功能限制和日期；找不到的请写“未知”，不要推测。然后给出三个可在10分钟内完成的演示任务。消息与原始链接：[粘贴]
```

## 02 低粉爆款对抗式审核

```text
我会提供账号粉丝量、该账号10条同类视频的公开互动，以及一条候选爆款的公开指标。请比较同账号基线，指出观察到的信号、缺失数据、可能的混杂因素，再给出两条需要额外验证的证据。禁止假定播放量和后台推荐机制。数据：[粘贴]
```

## 03 只基于实测生成脚本

```text
请将我的真实操作记录改成40–60秒的视频分镜。五段结构：结果/问题/输入/操作/边界。每段必须列“需要拍的实际画面、屏幕文字、字幕”。只用我给出的事实；工具没有通过测试的地方必须明确说明。我的记录：[粘贴]
```

## 04 AI 修改简历（不编造）

```text
你是简历编辑。请基于原始经历重写2–3条清楚的工作职责；严禁新造事实、公司名、项目、数据和技能。输出原文、改写版与仍需本人核实的信息。原始经历：[粘贴虚构样本或本人允许处理的脱敏内容]
```

## 05 封面标题批判

```text
我会给出标题、实际视频步骤、结论和局限。你需要扮演一名持怀疑态度的普通观众，判断标题是否夸大、正文能否兑现、用户是否能在3秒内理解问题。给出3个更准确的封面候选，每个不超过12个汉字。不要承诺播放、粉丝或收入。内容：[粘贴]
```

## 06 数据复盘

```text
分析我提供的真实作品表，明确分开“观察事实”“可能解释”“可验证实验”。指标没有的写“未提供”，不要猜测算法。选择下周一个需要保留的结构、一个要停止的动作，以及三条同类内容的单变量实验计划。表格：[粘贴]
```

## 07 商单交付审核

```text
请审查下面的品牌合作Brief，逐条检查：产品是否能实测；交付平台和数量；审核次数；授权使用范围；二次投流；排他；付款节点；AI内容与广告标识；是否要求未经验证的功效承诺。输出“已确认/待确认/高风险”的清单。不帮我虚构产品测评。Brief：[粘贴]
```
