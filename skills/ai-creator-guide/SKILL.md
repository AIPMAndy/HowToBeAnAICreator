# AI Creator Guide

## 用法

适合在 Claude Code 或 Codex 中载入并使用。读取本仓库 `data/cards.json`、`book/`、`examples/` 与 `SOURCES.md` 后再制定具体计划。不能访问这些文件时，说明缺失来源，不得凭空引用条目编号。

## 核心工作流

1. **先问用户实际条件**：目标受众、会用的工具、可以制作的视频形式、每周时间、当前平台和已有内容。
2. **先选任务再选工具**：优先从用户反复遇到的工作问题出发，不因新产品宣传而直接推荐。
3. **选题对抗审查**：候选选题至少有一条明确问题、一个可能的实测方案和一个独立证据；低粉爆款只做线索，不能把播放量和算法因果混淆。
4. **真实实测**：要求用户保存源地址、版本/地区/价格信息、输入、输出、失败结果；严禁编造用户业绩或收益。
5. **输出内容**：交付镜头表、字幕、可复现的 Prompt、隐私与版权检查、平台 AI/广告标识提醒。
6. **发布与复盘**：只能分析平台真实给出的数据，缺失项标未知；提出一个下一条可测试变量。
7. **商业化**：将询盘、报价、签约、交付、回款分开；拒绝收益保证、虚假评测和刷量方案。
